# 浏览器学习约束

约束横切节点 [浏览器学习](../../branch/流程/浏览器学习/浏览器学习.md)：规范类问题必须先联网学习再作答。

## 必须

1. 遇到不明白的 UI／前端／无障碍／设计规范问题 → **先派 `file_ops` 浏览器检索学习并给出出处，再作答**；
   出处＝可溯 URL ＋ 检索日期。
2. 检索走 `ff_lite.py search`（须 `:grant network`）；需正文再 `fetch`。
3. 每条新判据回写知识叶子或 [参考书目](../../knowledge/参考书目/参考书目.md)，
   末尾标 `[联网]`（附 URL）或 `[本地]`（未确证）。
4. 中国大陆网络现实：优先可达源（豆瓣读书、知乎、w3.org 中文资料、github.io 镜像）；
   长英文书名改中文书名或「单词＋出版社」检索。

## 禁止

- 未检索即凭印象回答规范问题，或把记忆里的旧阈值当作现行规范引用。
- 臆造 URL／书名／条款号；抓不到正文却标 `[联网]`。
- 把境外站点不可达当作「规范不存在」；不可达只降级为 `未实测`／`[本地]`。
- 用学习结果改写 WCAG 条款编号与阈值本身（见 [知识更新约束](../知识更新约束/知识更新约束.md)）。
- 整页正文入库（只传意图＋参数·见 [dependence](../../dependence/dependence.md)）；缓存落 tmp/，技能目录不留。

## 兜底

全部候选源不可达 → 记 `未实测`，结论限定为「规格建议」不判定合规，并在改进清单里列出待复核项。

## 违规后果

- 跳过检索＝结论无据，调用方按错误基线改码；
- 臆造 URL＝知识库污染，后续每次引用都继承错误；
- 不可达即否定＝漏判真规范，P0 项被降级。
