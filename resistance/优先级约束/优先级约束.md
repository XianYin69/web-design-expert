# 优先级约束

## 严重度定义

| 级 | 定义 | 例 |
|---|---|---|
| P0 阻断 | 一部分用户完全无法完成任务，或违反 AA 硬条款 | 键盘不可达、对比度不达标、320px 内容被裁 |
| P1 明显受损 | 可完成但错误率高、理解成本高或性能明显劣化 | 缺 error/loading 态、正文 12px、LCP 超标 |
| P2 品质 | 不阻断但破坏一致性与专业度 | 间距非阶梯、阴影层级混乱、令牌缺失 |
| P3 风格 | 无条款支撑的偏好 | 圆角大小、配色倾向 |

## 排序与归并

1. 输出顺序：P0 → P1 → P2 → P3，同级按受影响用户面降序。
2. 同根因合并为一条（如「字号阶梯混乱」归并 8 处现象），列影响范围。
3. 默认清单 ≤12 条；超出时保留全部 P0/P1，把 P2/P3 折叠为「品质批次」一条。
4. 每条必须带验收判据，无判据的降级为建议（P3）。

## 禁止

- 为显得严格而把 P2 抬成 P1；为显得温和而把 P0 写成 P2。
- 无严重度输出结论。
