# 性能与渲染预算

## 预算基线（4G / 中端机）

| 指标 | 目标 | 判定 |
|---|---|---|
| LCP | ≤2.5s | >4s 判 P0 |
| INP | ≤200ms | >500ms 判 P1 |
| CLS | ≤0.1 | >0.25 判 P1 |
| 首屏 JS | ≤170KB gzip | 超出需拆分理由 |
| 总传输 | ≤2MB 首屏 | 图片占大头时查媒体叶子 |

## 设计侧成因（评审重点）

- 大图未压缩/未 `srcset`、背景图铺满移动视口 → 直接判 LCP 风险。
- 自定义字体阻塞渲染、无 `font-display` → FOUT/跳动。
- 首屏轮播、视频自动播放、无限滚动预取过多 → LCP/INP 恶化。
- 大面积 `backdrop-filter`、多层阴影、`box-shadow` 动画 → 掉帧主因。
- 布局跳动源：图片无 `aspect-ratio`、广告位/骨架高度不定、字体替换。
- 交互卡顿源：主线程长任务里做动画、滚动监听同步读写布局。

## 检验动作

Performance 面板录一次主流程，看长任务与掉帧；Network 面板看首屏资源瀑布图。
