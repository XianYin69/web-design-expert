# 交互反馈

## 时效基线

| 场景 | 判据 |
|---|---|
| 点击/触摸响应 | ≤100ms 内出现视觉变化，否则视为无响应 |
| 输入即时校验 | 失焦时校验，不在每次按键报错 |
| 异步 >500ms | 必须出骨架/进度/禁用态 |
| 异步 >10s | 给可取消入口与失败兜底 |
| 动画时长 | 微反馈 120–160ms，展开/收起 200–300ms，页面级 ≤400ms |

## 反馈完整性

- 每个动作需三件：即时确认（按下态）、进行中指示、结果告知（成功/失败）。
- 破坏性操作：二次确认或可撤销（撤销窗口 ≥5s），禁止仅靠红色按钮免责。
- 提示（toast）不得遮挡主内容与表单提交按钮；自动消失时长按信息量分级（成功 3s、错误不自动消失）。
- 表单提交失败必须保留已填内容并定位到错误项（错误摘要置顶可跳转）。
- 空结果、离线、权限不足都要有明确文案与出路，不得静默。
