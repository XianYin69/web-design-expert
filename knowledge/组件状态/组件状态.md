# 组件状态

## 必备状态矩阵

每个可交互组件必须定义并可验证：`default / hover / focus-visible / active / disabled / loading / error / success / selected / empty`。

| 状态 | 判据 |
|---|---|
| hover | 变化可辨（色/阴影/位移），但不得作为唯一入口（触屏无 hover） |
| focus-visible | 与 hover 明显不同，键盘用户一眼可定位 |
| active | 有向下/缩放反馈，时长 ≤120ms |
| disabled | 对比可降但需给出原因；不可点击的控件不得可聚焦 |
| loading | 保留尺寸防跳动，配文字或 `aria-busy`，禁用重复提交 |
| error | 颜色＋图标＋文字三重表达，靠近出错字段 |
| empty | 说明为何为空＋给出下一步动作 |

## 判定规则

- 缺 loading/error/empty 任一 → P1（真实数据必然触发）。
- 状态用 `:hover` 直写而非令牌 → P2（主题切换会失配）。
- 状态间过渡只改 `transform/opacity/background-color`，禁止 `height` 抖动。
