# 色彩与对比度

## 硬判据（WCAG 2.2）

| 场景 | 阈值 |
|---|---|
| 正文（<18.66px 常规 / <24px 粗体） | ≥ 4.5:1 |
| 大文本（≥24px 或 ≥18.66px 粗体） | ≥ 3:1 |
| 图标、控件边框、焦点环、非文本必要信息 | ≥ 3:1 |
| 禁用态、装饰、Logo | 豁免 |
| 焦点指示器与相邻色 | ≥ 3:1（1.4.11 / 2.4.13） |

- 对比度用 [contrast_check.py](../../scripts/contrast_check.py) 实算，禁止目测放行。
- 半透明前景须按合成后的实际底色计算，不按名义色值。

## 用色规范

- 语义色固定映射：主色（品牌/主操作）、成功、警告、危险、信息；同一语义全站同色同形。
- 状态色不得只靠颜色区分（须配图标/文字/形状）→ 1.4.1 使用颜色。
- 中性灰阶梯 ≤ 6 级并命名（gray-50…900），禁止随手 `#333/#3a3a3a` 混用。
- 暗色模式避免纯黑纯白：底 `#121212` 级、文字 87% 白；大面积高饱和色需降饱和。
- 渐变/图片上的文字必须加遮罩或文字阴影并实测最坏区域对比度。
