# 评审清单

全维度体检时按序走一遍，命中即转成改进项（严重度定义见 [优先级约束](../../resistance/优先级约束/优先级约束.md)）。

## P0 候选（阻断）

- [ ] 键盘走不完主流程 / 存在焦点陷阱或焦点不可见
- [ ] 正文或关键控件对比度低于阈值（4.5:1 / 3:1）
- [ ] 320px 宽出现横向滚动或内容被裁切
- [ ] 触控目标 <24×24px 且无替代入口
- [ ] 表单错误不可识别、提交后内容丢失
- [ ] 图片缺替代文本导致信息缺失；图标按钮无可访问名
- [ ] 首屏 LCP 明显超标（大图/阻塞字体/自动轮播）

## P1 候选（明显受损）

- [ ] 缺 loading / empty / error 任一状态
- [ ] 断点处布局破损、侧栏不可用、吸底遮挡内容
- [ ] 正文 <15px 或行高 <1.4、行宽 >85 字符
- [ ] 层级只靠颜色或只靠字重表达
- [ ] 动效导致掉帧或布局跳动（CLS）
- [ ] 破坏性操作无确认或不可撤销

## P2/P3 候选（品质与风格）

- [ ] 间距出现非阶梯值、对齐不统一
- [ ] 阴影/圆角/图标风格混用
- [ ] 令牌缺失、组件内硬编码色值
- [ ] 微文案含糊（「确定」「暂无数据」「系统异常」）

## 用法

清单是入口不是结论：每条命中必须回到对应知识叶子取判据再写诊断。
