# 响应式与断点

## 判据

- 断点由内容决定，不由设备决定：在 320 / 768 / 1024 / 1440 处无内容破损、无横向滚动。
- 移动优先：基础样式服务窄屏，`@media (min-width)` 逐级增强；出现 `max-width` 主布局＝反模式。
- 流式尺寸：`clamp(min, preferred, max)` 处理字号/间距/容器宽；固定 px 宽度出现在主栏＝P1。
- 触控目标 ≥ 24×24 CSS px（WCAG 2.2 2.5.8），推荐 44×44；间距 ≥ 8px 防误触。
- 支持 200% 文字缩放不破版（1.4.4）；支持 320px 宽纵向单列可读（1.4.10）。
- 断点处布局变化必须有意义（重排/折叠/隐藏），禁止只是等比压缩。
- 侧栏/弹层在窄屏改全宽或抽屉；固定底栏需留 `env(safe-area-inset-bottom)`。
- 图片：`srcset`/`sizes` 或 `aspect-ratio` 容器，避免窄屏加载桌面尺寸大图。

## 检验动作

拖窄视口 320→1440 全程观察；每档检查：溢出、换行错位、隐藏内容、可点区域重叠、吸底遮挡。
