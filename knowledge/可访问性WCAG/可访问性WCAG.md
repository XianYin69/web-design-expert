# 可访问性 WCAG

## 评审必查（AA 底线）

| 条款 | 判据 |
|---|---|
| 1.1.1 替代文本 | 信息图必有 alt；装饰图 `alt=""`；图标按钮有可访问名 |
| 1.3.1 信息与关系 | 语义标签表达结构，表格有 `th`/`scope` |
| 1.4.1 使用颜色 | 颜色不是唯一信息载体 |
| 1.4.3 / 1.4.11 对比度 | 文本 4.5:1、非文本 3:1 |
| 1.4.4 文字缩放 | 200% 不破版 |
| 1.4.10 回流 | 320px 宽不需横向滚动 |
| 2.1.1 / 2.1.2 键盘 | 全功能可键盘操作，无焦点陷阱 |
| 2.4.3 焦点顺序 | DOM 顺序＝逻辑顺序 |
| 2.4.7 焦点可见 | 焦点环对比 ≥3:1，禁止 `outline:none` 无替代 |
| 2.5.3 标签名称 | 可访问名包含可见文本 |
| 2.5.7 拖拽替代 | 拖拽操作有单点替代 |
| 2.5.8 目标尺寸 | ≥24×24 CSS px |
| 3.2.1 / 3.2.2 | 聚焦或输入不触发意外跳转/提交 |
| 3.3.1 / 3.3.2 | 错误可识别且指明修法，控件有持久标签 |
| 3.3.7 冗余输入 | 同流程不重复索取已填信息 |
| 4.1.2 名称/角色/值 | 自定义控件暴露语义 |

## 判定方式

先跑 [a11y_probe.py](../../scripts/a11y_probe.py) 静态扫，再键盘实测＋读屏抽查（NVDA / VoiceOver 各一遍主流程）。
