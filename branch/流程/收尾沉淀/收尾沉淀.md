# 收尾沉淀

## 动作

1. 交付报告：按 [评审报告模板](../../../asset/评审报告模板.md) 输出结论、清单、复测判定。
2. 沉淀经验：本次新得的判据/阈值写入对应知识叶子（只增不改规范条款），并记逻辑链。
3. 释放工作区：tmp/ 过程产物经垃圾回收核对后删除，技能目录不留缓存。
4. 返回调用方：把「结论 + 剩余风险 + 建议下一步」交回 SMS 主流程或调用技能，由其续排任务表。

## 完成标志

报告已交付 + 复测判定已给出 + tmp 已清理 → **完成**（本技能流程结束，不进入修改流程）。
