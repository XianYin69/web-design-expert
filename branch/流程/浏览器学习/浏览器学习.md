# 浏览器学习

横切节点：不属于线性路径的某一步，任一步骤遇到**不明白的 UI／前端／无障碍／设计规范问题**时强制触发。

## 触发条件

- 判据不在 [knowledge/](../../../knowledge/knowledge.md) 十四叶／参考书目内，或条目已过时、口径存疑。
- 调用方给出本技能未覆盖的技术（新 CSS 特性、框架约定、平台 HIG、新 WCAG 条款）。
- 需要引用规范原文、书名版本、阈值出处才能下 P0/P1 结论。

## 强制顺序（不得跳步）

1. **先检索再作答**：派 `file_ops` 的 `ff_lite.py search "<关键词>"`（须 `:grant network`），
   必要时 `fetch <url>` 取正文；未检索**禁止**凭印象回答规范问题。
2. **中国大陆可达性**：境外站点 fetch 常 `WinError 10060`，优先可达源——
   豆瓣读书 `book.douban.com`、知乎、`w3.org` 中文资料、`github.io` 镜像；
   ≥4 词英文书名会被搜索引擎切成词典页，改用中文书名或「单词＋出版社」。
3. **给出出处**：答复中附 URL 与检索日期；抓不到正文只拿到标题/链接时降级为 `推断`。
4. **回写知识库**：确证后把结论补进对应知识叶子或 [参考书目](../../../knowledge/参考书目/参考书目.md)，
   条目标 `[联网]`（附可溯 URL）或 `[本地]`（未确证）；**禁止臆造 URL**。
5. **不可达降级**：全部候选源不可达 → 记 `未实测`，按 [证据约束](../../../resistance/证据约束/证据约束.md)
   只给「规格建议」，不判定合规。

## 出口

- 学到新判据 → 回原步骤继续（多为 [领域路由/](../领域路由/领域路由.md) 或 [专家诊断/](../专家诊断/专家诊断.md)）。
- 无新知识（命中已有叶子）→ 直接回原步骤，不留痕。
