# 改进清单

把诊断转成可执行、可验收的改动项，输出用 [评审报告模板](../../../asset/评审报告模板.md)。

## 每条改进项的字段

| 字段 | 要求 |
|
|---|---|
| 动作 | 祈使句，指明改哪个元素/令牌 |
| 规格 | 给出具体数值或代码片段（可直接粘贴） |
| 严重度 | P0 阻断 / P1 明显受损 / P2 品质 / P3 风格 |
| 验收 | 一条可测判据（如「Tab 顺序＝视觉顺序且焦点可见」） |
| 成本 | XS/S/M/L，供排期取舍 |

## 排序规则

P0 全部列完 → P1 按受影响用户面从大到小 → P2/P3 合并成「品质批次」一条。
清单条数默认 ≤12 条；超出时按 [优先级约束](../../../resistance/优先级约束/优先级约束.md) 归并同因项。

## 出口

清单交付 → 进入 [复审确认/](../复审确认/复审确认.md)。
