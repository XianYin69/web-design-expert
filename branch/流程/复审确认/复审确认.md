# 复审确认

改动落地后复测，判定「通过 / 部分通过 / 回归」。

## 复测动作

1. 逐条对照改进项的验收判据实测（对比度重算、键盘重走、断点重拖、预算重采）。
2. 检查是否引入回归：新遮挡、新焦点陷阱、新横向滚动、新布局跳动（CLS）。
3. 未通过项回到 [专家诊断/](../专家诊断/专家诊断.md) 重判，最多两轮；仍不过则升级给用户决策。

## 判定口径

| 结论 | 条件 |
|---|---|
| 通过 | 全部 P0/P1 验收通过，无新增回归 |
| 部分通过 | P0 通过，P1 有遗留且已标注风险 |
| 不通过 | 任一 P0 未过或出现新阻断项 |

## 出口

判定完成 → 进入 [收尾沉淀/](../收尾沉淀/收尾沉淀.md)。
