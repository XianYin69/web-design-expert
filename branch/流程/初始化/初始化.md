# 初始化

## 目的

建立本次评审的工作空间与口径，保证后续判断可追溯。

## 动作

1. 确认调用方（SMS 主流程 / 编码技能 / 用户直调）与交付形态：口头结论 or 报告文件。
2. 确认评审范围：整站、单页、单组件、还是某段样式；确认目标平台与浏览器基线。
3. 确认知识口径：默认 WCAG 2.2 AA＋现代 CSS/布局实践；调用方可显式改写。
4. 工作产物一律写入 tmp/（不写入技能目录），过程状态用过程链存档。
5. 若范围或平台不明，先提问一次；未答则按「桌面＋移动、AA 合规」默认继续并声明假设。

## 出口

范围与口径确定 → 进入 [需求确认/](../需求确认/需求确认.md)。
