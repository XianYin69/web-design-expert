# 证据采集

专家判断必须建立在可见证据上，禁止凭截图印象编造实现细节。

## 证据类型与取法

| 证据 | 取法 | 用途 |
|---|---|---|
| 结构 | 读 HTML/JSX 语义标签顺序 | 判断语义与可访问性骨架 |
| 样式 | 读 CSS/令牌文件、媒体查询 | 判断断点、层级、对比度 |
| 计算值 | 浏览器 devtools 取 computed style | 字号、行高、间距实际值 |
| 色彩 | 取前景/背景色值算对比度 | 见 [色彩与对比度](../../../knowledge/色彩与对比度/色彩与对比度.md) |
| 键盘 | 只用 Tab/Enter/Esc 走一遍流程 | 焦点顺序与可见性 |
| 运行时 | Lighthouse / Performance 面板 | 渲染预算与主线程占用 |
| 视觉 | 截图或设计稿 | 层级、对齐、留白节奏 |

## 缺证处理

- 拿不到的证据 → 在结论里标 `未实测`，并给出取法建议，不得当作已验证。
- 只有设计稿时 → 结论限定为「规格建议」，不判定合规。
