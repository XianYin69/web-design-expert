# 评审报告模板

交付形态：调用方要文件则按本模板落 tmp/ 后转交；只要结论则只出「结论＋P0/P1 清单」。

## 模板

```markdown
# 设计评审：<对象名>
- 范围：<整页/组件/样式片段>　平台：<桌面/移动/双端>　口径：<WCAG 2.2 AA / 现代 CSS 实践>
- 证据：<实测 / 静态 / 推断 / 未实测>　复测轮次：<n>

## 结论
一句话判定：通过 / 部分通过 / 不通过，附最关键的一条根因。

## 改进清单
| 级 | 维度 | 现象与证据 | 依据 | 动作与规格 | 验收 | 成本 |
|---|---|---|---|---|---|---|
| P0 |  |  |  |  |  |  |

## 剩余风险与未实测项
- （列出拿不到证据的项与取法建议）

## 建议下一步
- （交回调用方：改代码 / 复审 / 转其他技能）
```

## 用法

1. 逐条判断句式：现象（含数值）→ 依据（知识叶子/条款）→ 用户侧后果。
2. 清单可用脚本生成：`python scripts/design_review.py findings.json --out report.md`。
3. 对比度数值用 `python scripts/contrast_check.py <前景> <背景>` 实算后填入。
4. 静态异味用 `python scripts/a11y_probe.py <目标>` 扫，命中项仍需人工复核。
